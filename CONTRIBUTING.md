# Contributing to Stellar Gaming Hub Frontend

Thank you for your interest in contributing to **Stellar Gaming Hub**! We welcome contributions from developers, designers, and web3 enthusiasts.

---

## 🚀 Code of Conduct

By participating in this project, you agree to maintain a respectful, inclusive, and welcoming environment for all contributors.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs & Features
- Check existing [GitHub Issues](https://github.com/stellar-gaming-hub/Gaming-frontend/issues) before submitting a new report.
- Open an issue with a clear title, description, and steps to reproduce bugs or request features.

### 2. Submitting Pull Requests
1. Fork the repository and create your feature branch:
   `git checkout -b feature/your-feature-name`
2. Commit changes using semantic prefixes (`feat:`, `fix:`, `docs:`).
3. Open a Pull Request against the `main` branch.

---

## 💎 Drips Protocol & Grants

Core contributions and resolved issues may be eligible for continuous funding streams or retroactive grants via the **Drips Protocol**.
